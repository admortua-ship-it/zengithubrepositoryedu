# README
This is just a repository in my school account for some random stuff.

The following entries are in place:

[Score Calculator V1, General](pass_or_bagsak.py)

This calculates whether you have passed or not based on a test's maximum score, your actual score, and optionally the set passing threshold. It tells you how close you are to the threshold, how many mistakes you made, and, of course, whether you passed.

We plan to add a remarks system, as well as alternative modes for different kinds of tests or activities.

[Permutation & Combination Calculator, Statistics I](perm_or_comb.py)

Calculates how many ways to form permutations or combinations from a set of items of a chosen length.
